「SDK」指本文件夹中的内容：说明书、接口定义、接口参考、指南、TypeScript 类型声明与 Rust SDK。「工具」指装环境脚本安装的 tessoa-plugin 命令行工具，包括其中内含的插件运行器。

## 你可以

无需付费、无需征得我们同意、也无需保留任何声明，你可以：

1. 用 SDK 和工具编写、构建、测试、打包和安装 tessoa 插件；
2. 向任何人发布你构建的插件，免费或收费均可，条款由你决定。这包括构建时放进插件的 SDK 部分，例如 Rust 插件里编译进去的 Rust SDK；
3. 把本文件夹按插件模板的放法留在你的插件源码仓库里，并连同它分享或发布该仓库，私有或公开均可；
4. 制作帮助他人构建 tessoa 插件的工具，例如编辑器扩展、检查工具或你自己的模板，并在其中附带 SDK。

## 你不可以

1. 单独分发 SDK（随插件源码仓库、或随上面第 4 项所说的工具一起分发的除外），或把改动过的 SDK 当作我们发布的 SDK 分发。
2. 分发工具。工具由我们通过装环境脚本提供，脚本会按插件模板里的指纹核对每一次下载。
3. 用 SDK 或工具制作让人在 tessoa 之外使用 tessoa 插件的软件，例如加载这些插件的其他应用程序。上面第 4 项所说的、只为测试而运行插件的工具不在此列。
