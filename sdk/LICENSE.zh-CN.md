SDK 指本文件夹中的内容：说明书、接口定义、接口参考、指南、TypeScript 类型声明与 Rust SDK。

## 你可以

无需付费、无需征得我们同意、也无需保留任何声明，你可以：

1. 用 SDK 编写、构建、测试和打包 tessoa 插件；
2. 向任何人发布你构建的插件，免费或收费均可，条款由你决定。这包括构建时放进插件的 SDK 部分，例如 Rust 插件里编译进去的 Rust SDK；
3. 把本文件夹按插件模板的放法留在你的插件源码仓库里，并连同它分享或发布该仓库，私有或公开均可。

## 你不可以

不得单独分发 SDK（上面所说的、随插件源码仓库一起的情形除外），也不得用它构建 tessoa 插件以外的软件。

SDK 按「现状」提供，不附带任何明示或默示的担保。在适用法律允许的范围内，版权人不对因 SDK 或其使用而产生的任何索赔、损害或其他责任负责。

## 其他

在 tessoa 中安装你的插件的人，适用《tessoa 插件条款》；本许可只约定你可以用 SDK 做什么。本许可与其英文版本（LICENSE.md）含义不一致的，以中文版为准。
